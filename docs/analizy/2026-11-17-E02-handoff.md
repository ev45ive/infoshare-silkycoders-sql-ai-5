## Zapytania (SQL)

Krok 3 (widok):

```sql
SELECT YearMonth, Channel, SUM(NetAmount) AS NetAmount, SUM(GrossAmount) AS GrossAmount
FROM reporting.vw_SalesDaily
WHERE SalesDate >= '2026-07-01' AND SalesDate < '2026-09-01'
GROUP BY YearMonth, Channel
ORDER BY YearMonth, Channel;
```

Krok 4 (zwroty):

```sql
SELECT st.Channel, COUNT(*) AS ReturnRows, SUM(r.ReturnAmount) AS ReturnGross,
       CAST(SUM(r.ReturnAmount)/1.23 AS DECIMAL(18,2)) AS ReturnNetApprox
FROM dbo.FactReturns r
JOIN dbo.DimStore st ON st.StoreKey = r.StoreKey
JOIN dbo.DimDate d ON d.DateKey = r.DateKey
WHERE d.YearMonth = '2026-08'
GROUP BY st.Channel;
```

Krok 2 (LoadLog):

```sql
SELECT TOP (10) LoadId, PackageName, StartedAt, FinishedAt, Status, RowsRead, RowsLoaded, RowsRejected
FROM dbo.LoadLog
WHERE PackageName = N'etl.LoadSales'
ORDER BY LoadId DESC;
```

Krok 5 (duplikaty w fakcie, sierpień):

```sql
WITH x AS (
    SELECT f.TransactionNo, f.LineNumber, f.NetAmount, st.Channel,
           ROW_NUMBER() OVER (PARTITION BY f.TransactionNo, f.LineNumber ORDER BY f.SalesKey) AS rn
    FROM dbo.FactSales f
    JOIN dbo.DimDate d ON d.DateKey = f.DateKey
    JOIN dbo.DimStore st ON st.StoreKey = f.StoreKey
    WHERE d.YearMonth = '2026-08'
)
SELECT Channel, COUNT(*) AS Lines,
       SUM(CASE WHEN rn > 1 THEN 1 ELSE 0 END) AS ExtraCopies,
       SUM(CASE WHEN rn > 1 THEN NetAmount ELSE 0 END) AS ExtraNet,
       SUM(NetAmount) AS Net
FROM x
GROUP BY Channel;
```

Krok 4 (duplikaty w źródle, sierpień, według pliku):

```sql
SELECT r.SourceFile, COUNT(*) AS RawRows
FROM src.SalesRaw r
WHERE r.SalesDate LIKE '2026-08-%'
GROUP BY r.SourceFile
ORDER BY r.SourceFile;
```
