## Zapytania (SQL)

Krok 3 (widok):

```sql
SELECT YearWeek, Channel, SUM(NetAmount) AS NetAmount, SUM(GrossAmount) AS GrossAmount, SUM(Units) AS Units
FROM reporting.vw_SalesWeekly
WHERE IsoYear = 2026 AND IsoWeek IN (37, 38)
GROUP BY YearWeek, Channel
ORDER BY YearWeek, Channel;
```

Krok 4 (fakt + duplikaty):

```sql
SELECT d.YearWeek, st.Channel, SUM(f.NetAmount) AS NetAmount, SUM(f.GrossAmount) AS GrossAmount,
       SUM(f.Quantity) AS Units, COUNT(*) AS LineRows, MIN(f.DateKey) AS MinDateKey, MAX(f.DateKey) AS MaxDateKey
FROM dbo.FactSales f
JOIN dbo.DimStore st ON st.StoreKey = f.StoreKey
JOIN dbo.DimDate d ON d.DateKey = f.DateKey
WHERE f.DateKey BETWEEN 20260907 AND 20260920
GROUP BY d.YearWeek, st.Channel
ORDER BY d.YearWeek, st.Channel;

SELECT COUNT(*) AS DuplicateKeys, ISNULL(SUM(c - 1), 0) AS ExtraRows
FROM (SELECT TransactionNo, LineNumber, COUNT(*) AS c
      FROM dbo.FactSales WHERE DateKey BETWEEN 20260907 AND 20260920
      GROUP BY TransactionNo, LineNumber HAVING COUNT(*) > 1) x;
```

Krok 5 (seria, W23-W38):

```sql
SELECT IsoWeek, MIN(WeekStart) AS WeekStart, MAX(WeekEnd) AS WeekEnd,
       SUM(CASE WHEN Channel = 'STORE'  THEN NetAmount END) AS StoreNet,
       SUM(CASE WHEN Channel = 'ONLINE' THEN NetAmount END) AS OnlineNet
FROM reporting.vw_SalesWeekly
WHERE IsoYear = 2026 AND IsoWeek BETWEEN 23 AND 38
GROUP BY IsoWeek ORDER BY IsoWeek;
```

Krok 7 (drill-down STORE, W37 vs W38; zamiana `Region` na `Category` daje drugi przekrój):

```sql
SELECT Region,
       SUM(CASE WHEN IsoWeek = 37 THEN NetAmount END) AS W37,
       SUM(CASE WHEN IsoWeek = 38 THEN NetAmount END) AS W38
FROM reporting.vw_SalesWeekly
WHERE IsoYear = 2026 AND IsoWeek IN (37, 38) AND Channel = 'STORE'
GROUP BY Region;
```

Krok 2:

SELECT TOP (10) LoadId, PackageName, StartedAt, FinishedAt, Status,
       RowsRead, RowsLoaded, RowsRejected, LEFT(ErrorMessage, 200) AS ErrorMessage

ORDER BY LoadId DESC;
